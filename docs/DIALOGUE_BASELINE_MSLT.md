## 根因修正（导入 A/B）

首轮基线把「中文识别极差」当成产品洞，核对后发现是 **考卷做错**：

- MSLT `T2`/`T3` 是**多行整段**转写/译文
- `import_mslt_dialogue.py` 的 `_read_member` **只取了第一行**
- 于是参考变成「对。」，wav 却是 28s 整段话 → 假性「识别超长」

## 本轮改动（不动 VAD 三阈值）

1. **短回应放行**：`MIN_FINAL_ASR_SHORT_OK` + dual_track 不因 1 字「对/嗯」跳过 MT  
2. **空 partial 离线救回**：即将 `empty_abort` 前 SenseVoice oneshot；假名短回应（うん/はい/な/いん…）在中文方向映射为 嗯/对  
3. **zh→en postedit 多子句 scrub**：日货/买日→day、外卖→takeaway、宅→at home、整个带→big；新疆 ⁇ 仍修  
4. **TM** 补对话短句；长句 beam 阈值保持
