## 最大短板（一句话）

**中→英的中文识别最差（可用仅 13%），译文可用被它拖到 33%；半句/多句碎切约 17% 是第二位。英→中相对健康（ASR 63% / 译文 80%）。**

因此下一步不应先盲改「半句合并」，而应先啃 **zh 侧 ASR 超长/错识**（含：单条 wav 是否长于参考句、幻觉、空识别），再用同一脚本回归。
