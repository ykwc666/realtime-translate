# 补测（2026-11-05）：0.4 实际是跨档改善，上一轮结论被闸门误杀

上一节的表只到 harness 层（rescued / normal / synth），**没有跑 P2 ledger**，所以
"7/16 太小、不值得继续" 是个未经检验的判断。补跑后结论反转。

## 1. 两个闸门本身不成立

| 闸门 | 问题 |
|---|---|
| `normal_ok >= 24` | `normal` 集只有 22 条（= 基线 ok 集）。**任何候选都不可能通过**，含基线自己。原文承认了这点（"本轮满额即 22/22"），但闸门仍返回 False，于是按 FAIL 处理 |
| `synth_same == 3` | 要求合成集文本逐字不变 → **把"切对了"也记成回归**（详见下） |

已修：`normal_ok >= len(normal)`；新增 `synth_no_loss`，只在**丢句**时判失败。

## 2. 0.4 的 synth "回归"其实是修好

`cache/ab_weekday/accept_phrases.wav` 有 5 个语音区（0–0.58 / 2.24–3.64 / 5.2–6.54 /
8.02–9.2 / 10.68–13.9s）。VAD 层实测切点：

| 阈值 | 段数 | 对齐 |
|---|---|---|
| 0.5 | 4 | 第 2 个语音区（2.24–3.64s）缺失 |
| 0.45 | 5 | 与 5 个语音区逐一对应 |
| 0.4 | 5 | 与 5 个语音区逐一对应 |

